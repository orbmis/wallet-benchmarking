What the cell colours mean

Colour = better / worse for the user

Not literally yes/no — e.g. "sends usage analytics: Yes" shows red, because it's worse for the user.

  • Good favourable for the user
  • Worse unfavourable
  • Partial partial / qualified support
  • — Unknown not recorded in the dataset (distinct from "No")
  • N/A not applicable to this wallet type (e.g. product features on hardware wallets)
  • Value a descriptive value (e.g. a licence) rather than yes/no
Reading the comparison
  • Your baseline column is highlighted and marked ★.
  • A rival cell that differs from your baseline is outlined — that's where you win or lose.
  • The scorecards up top give each wallet a favourability % and a delta vs. you.
  • Click any cell to open the evidence drawer: the verdict, your baseline's value side-by-side, and the source links. Values sourced only to a refTodo placeholder are flagged ⚠ Unsourced.

How to use it

  • Set your wallet in "Baseline wallet", then toggle the wallet chips (split into Hardware and Software) to compare against.
  • Platform filters to wallets that ship on Browser / Mobile / Desktop, so you compare a fair peer set.
  • Only differences hides rows where every rival matches you; Hide unknowns declutters un-recorded rows.
  • Search filters rows by name; category headers collapse; Export CSV dumps the current view for slides/sheets.

Coverage varies by wallet — an "Unknown" cell means the dataset hasn't recorded that fact yet, not that the answer is "no".
